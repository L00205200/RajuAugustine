About this site

This is a static website. The HTML and CSS files are stored in a private Amazon S3 bucket and delivered over HTTPS by Amazon CloudFront. All of the supporting infrastructure is provisioned by an AWS CloudFormation template.

Architecture

  1. Browser requests the page over HTTPS.
  2. CloudFront serves the page from the nearest edge location, using its cache where possible.
  3. S3 stores the files in a private, encrypted and versioned bucket.

The bucket cannot be accessed directly. Only this CloudFront distribution is permitted to read from it, through Origin Access Control.

Best practices applied

  • Private bucket with all public access blocked
  • HTTPS enforced: HTTP is redirected, and S3 rejects non-TLS requests
  • Security headers added by CloudFront (HSTS, X-Frame-Options and others)
  • Encryption at rest and versioning enabled on the bucket
  • Templates validated with cfn-lint and checkov on every pull request
